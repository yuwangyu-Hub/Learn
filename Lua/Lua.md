## 1 Lua语言入门

​	遵照管理，第一个Lua程序通过标准输出打印字符串“hello world”

​		print("hello world")

复杂例子，以下代码定义了一个计算阶乘的函数，用户输入一个数，在打印这个数的阶乘结果。

```lua
--定义一个计算阶乘的函数
function fact(n)
	if n == 0 then
		return 1
	else
  	return n * fact(n-1)
	end
end
print("enter a number:")
a = io.read("*n") --读取一个数字
print(fact(a))
```

### 1.1 程序段

​	Lua语言执行的每段代码（例如一个文件或交互模式下的一行），成为一个程序段（Chunk），一组命令或表达式组成的序列。

​	程序段既可以是一句简单的表达式（例如”hello world“），也可以由多个表达式和函数构成。大小上没有限制。由于Lua语言可以被用做数据定义语言，所以Lua语言解释器可以支持几MB的程序段。

​	除了将代码保存成文件用解释器运行外，还可以在控制台以交互式的方式独立运行解释器。

### 1.2 词法规范

​	Lua语言中的标识符（名称）可以用任意字母、数字和下划线组成的字符串（不能以数字开头），例如：i、j、i10、_ij、asomeWhatLongName、_INPUT 等。

​	“下划线+大写字母”（例如_VERSION）组成的标识符常被Lua当作特殊用途，所以应该尽可能避免这种写法。

#### 1.2.1 关键字

以下是Lua语言的保留字，他们不能被用做标识符：

|    and    |   break    |     do     |   else   |    elseif    |
| :-------: | :--------: | :--------: | :------: | :----------: |
|  **end**  | **false**  |  **goto**  | **for**  | **function** |
|  **if**   |   **in**   | **local**  | **nil**  |   **not**    |
|  **or**   | **repeat** | **return** | **then** |   **true**   |
| **until** | **While**  |            |          |              |

​	Lua语言对大小写敏感，所以and是保留字，但是And和AND是两个不同的标识符。

#### 1.2.2 注释

​	Lua语言中使用两个连续连字符（--）表示单行注释的开始，从--后的次行所有内容都是注释。使用“两个连续连字符加两个连续左方括号” 加内容加“两连续连字符加两个连续右方括号”可表示多行注释，例如：

```lua
--单行注释内容，不会被识别
--[[
多行注释内容，
不会被识别
]]--
```

### 1.3 全局变量

在Lua中，全局变量无须声明即可使用，使用没有初始化的全局变量也不会导致错误，会得到nil

​	> b          --> nil

​	> b = 10

​	> b          --> 10

当把nil赋值给全局变量时，Lua会回收该全局变量，就像该变量没有出现过。

### 1.4 类型和值

​	Lua语言是一种动态类型语言（Dynamically-typed Language），没有类型定义（type definition），每个值都有其自身类型信息。

​	Lua中有8种基本类型：nil（空）、boolean（布尔）、number（数值）、string（字符串）、userdata（用户数据）、function（函数）、thread（线程）、table（表）。使用type可获取该值对应的类型名称。
